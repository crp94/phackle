# The Goal

**P-hackle is a world-class daily game about p-hacking.** Not "correct and complete" — world-class, under every angle at once:

- **Scientific:** every statistical claim in the game is true; the engine's DGP/OLS/t machinery is numerically sound; the pedagogy teaches real methods literacy (a methods-literate player finds nothing to correct; a newcomer leaves knowing what a forking path is).
- **Computational:** deterministic, fast, small; no state the code can reach that the design didn't intend; the daily puzzle is identical for every player on every platform.
- **Writing:** every string earns its place; the comedy is brave in Act I and silent in Act II; all three languages read as if originally written by a native speaker *of that language's academia* — prose AND interface chrome (buttons, labels, states follow each locale's software conventions, never calqued).
- **UX/UI:** learnable in 30 seconds, a full day playable in under 3 minutes, flawless one-handed at 360px, both themes, motion that means something, accessible as a first-class experience.

The standard is the world's best daily puzzle games, stated as properties (see the grand-review plan) — no publication or competitor is ever named in any artifact.

**Process:** iterate — review from first principles, fix, verify, re-review — until every lane is clean. The grand review (docs/superpowers/plans/2026-08-04-grand-review.md) runs before deploy. Owner feedback rounds outrank everything else in the queue. Deploy requires the owner (Vercel link, DNS, analytics, EPOCH freeze).
