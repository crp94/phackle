# P-hackle v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship P-hackle v1 — the daily p-hacking game — per `docs/implementation_plan.md` (master spec) + `docs/superpowers/specs/2026-08-03-phackle-v1-design.md` (approved deltas), trilingual EN/IT/ES, deployed on Vercel.

**Architecture:** Pure deterministic TypeScript statistical engine in a Web Worker (owns the day's data; UI never sees raw rows or day type before reveal); Zustand store drives the BRIEFING→LAB→PUBLISHED→CALL→REVEAL→SUMMARY machine; content is per-locale typed data modules with compile-time exhaustiveness; static Vite build, no backend.

**Tech Stack:** Vite (latest) + React 19 + TypeScript strict + Tailwind 4 + Zustand 5 (plain store, hand-rolled versioned persistence) + Vitest + @testing-library/react + Playwright + vite-plugin-pwa + @vercel/analytics. No chart libs, no i18n libs, no stats libs.

## Global Constraints

Every task implicitly includes these. Read master spec §§ cited in your task **before coding**.

- **Determinism:** same date ⇒ byte-identical puzzle on all clients. Engine uses only `+ − × ÷ sqrt exp log` on f64, `Math.imul`; **never** `Math.pow` with non-integer exponents, never `Math.random` (§3.1).
- **Engine purity:** `src/engine/**` imports nothing from `react`, `src/ui`, `src/game`, `src/i18n`, `src/content` (ESLint-enforced from T1). Engine is language-blind.
- **Content is data:** no user-facing string literals in components — everything through the locale copy catalog / content modules (delta spec). Missing translations must be `tsc` errors.
- **All balance constants live in `src/game/tuning.ts`** (§3.9). Never inline a tunable number.
- **Register:** Act I copy sincere/enthusiastic, Act II clinical, never smug (§1.2). Journal mastheads + DOIs stay English in all locales. Statistical decimals use `.` in all locales (`p = 0.049`).
- **Spoiler rule:** share strings never leak day type or call direction (§2.9).
- **TDD:** every task = failing test → verify fail → implement → verify pass → commit. Run `npm test` (and `npm run lint && npx tsc --noEmit`) before every commit.
- **Commits:** small, imperative, `feat:/test:/fix:/chore:` prefixes; end body with the session trailer used in this repo's history.
- **Toolchain:** Node 22 (`.nvmrc`), npm. Repo root = game root (no nested app dir).
- **When plan and master spec conflict:** the delta spec > this plan > master spec; flag conflicts in your report, don't silently deviate (CLAUDE.md).

**Pins:** `R[i][j] = 0.35^|i-j|` (8×8 AR(1), PSD by construction); Cholesky **computed in TS at module load** by textbook `chol()` (allowed ops only) and unit-tested against a checked-in python-generated fixture. Covariate constructions exactly §3.2 table. Treatment: `X = 1[0.3·L1 + 0.2·L4 + 0.94·ε > 0]`. Outcome loadings (in `dgpConstants.ts`, TUNABLE, calibration may adjust):
Y1 = 0.20·L1 + 0.20·L4 + 0.15·L6 + 1.0·t5(rng); Y2 = exp(0.4·(0.15·L1 + 0.25·L5 + 0.15·L6) + 0.5·z) (positive skew); Y3 = round(exp(0.8 + 0.15·L3 + 0.15·L4 + 0.15·L6 + 0.4·z)) (count); Y4 = clamp(round(5.5 + 1.4·(0.20·L5 + 0.15·L6) + 1.4·z), 1, 10). `t5(rng) = z0 / sqrt((z1²+…+z5²)/5)`.
